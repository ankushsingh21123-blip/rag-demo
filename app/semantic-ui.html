No generative LLM is connected. Similarity is not a confidence score.

Synthetic data only. Do not enter private or customer information. Query text and vectors reach this demo's backend but are not saved by the app. The database contains only eight fixed fictional passages.

Read-only RPC access. No document upload, login, billing or write endpoint. A 0.30 similarity threshold is a demo heuristic, not a guarantee that a passage answers the question.

Free-tier hosts can pause or reach limits. This is implementation evidence, not a production service, employer assessment or claim of unaided authorship.

Open-source dependencies: Transformers.js (Apache-2.0), LangChain (MIT), FastAPI (MIT), all-MiniLM-L6-v2 (Apache-2.0), PostgreSQL and pgvector (PostgreSQL licence). Source and verification notes
